# Elarion | Un escape mágico... de verdad

Elarion es un sitio web turístico ficticio dedicado a un reino mágico oculto en nuestro mundo.

El proyecto fue desarrollado como parte de mi formación en desarrollo web y tiene como objetivo poner en práctica conceptos de **HTML5, CSS3, diseño responsive, estructura semántica y navegación entre páginas**.

## 🌐 Demo

Podés visitar el sitio acá:

👉 https://hotiel.github.io/elarion/

## 📖 Sobre el proyecto

Según la historia de Elarion, un antiguo portal conecta nuestro mundo con un reino mágico cuya ubicación cambia constantemente.

La web funciona como una pequeña oficina de turismo del reino y permite a los visitantes conocer sus principales destinos, historia y gastronomía.

### Secciones

- **Inicio:** Presentación de Elarion y del portal que conecta ambos mundos.
- **Historia:** Origen y descubrimiento del reino.
- **Lugares:** Principales destinos turísticos de Elarion.
- **Gastronomía:** Ingredientes, platos típicos y recomendaciones gastronómicas.
- **Contacto:** Información para comunicarse con la Oficina de Turismo de Elarion.
